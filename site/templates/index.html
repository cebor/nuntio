Features

GPU rendering

One wgpu pipeline draws backgrounds, glyphs and UI. Box-drawing characters are drawn procedurally, so TUI borders line up without gaps.

Tabs and split panes

Drag tabs to reorder, split side by side or top and bottom, resize with keyboard or mouse, zoom a pane to fill the tab.

Hot reload

Save the config and it applies right away. Mistakes show up as a banner, and the previous settings stay active.

Themes

Five built in, your own as TOML or iTerm2 .itermcolors, and a light/dark pair that follows the OS appearance.

Text done right

Shaped with cosmic-text: font fallback, color emoji, CJK and wide characters.

Find bar

Incremental search through the scrollback, with a regex mode.

WSL on Windows

shell = { wsl = "Ubuntu" } opens every tab straight in a WSL distribution.

Idle means idle

nuntio only redraws when something changed, so an idle window uses close to 0% CPU.

Configure it in one file

Every setting is optional. Put this in ~/.config/nuntio/config.toml on any platform:

[font]
family = "JetBrains Mono"
size = 14.0

# Follow the OS appearance
[theme]
light = "Solarized Light"
dark = "Tokyo Night"
