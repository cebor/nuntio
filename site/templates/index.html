A fast terminal with tabs, split panes and a config that reloads while you type.

nuntio is a GPU-rendered terminal emulator for Linux, macOS and Windows, modeled on iTerm2. One window, one TOML file, close to 0% CPU when idle.

Features

GPU rendering

One wgpu pipeline draws backgrounds, glyphs and UI. Box-drawing characters are drawn procedurally, so TUI borders line up without gaps.

Tabs and split panes

Drag tabs to reorder, split side by side or top and bottom, resize with keyboard or mouse, zoom a pane to fill the tab.

Hot reload

Save the config, or change it in nuntio-config, and it applies right away. Mistakes show up as a banner, and the previous settings stay active.

Themes

Five built in, your own as TOML or iTerm2 .itermcolors, and a light/dark pair that follows the OS appearance.

Text done right

Shaped with cosmic-text: font fallback, color emoji, CJK and wide characters.

Find bar and status bar

Incremental search through the scrollback, with a regex mode. An optional status bar graphs CPU, memory, network and battery, as in iTerm2.

WSL on Windows

shell = { wsl = "Ubuntu" } opens every tab straight in a WSL distribution.

Idle means idle

nuntio only redraws when something changed, so an idle window uses close to 0% CPU.

Everything is a terminal. Even the settings.

Run nuntio-config in any nuntio tab. Settings are grouped by section, choices offer only valid values, and themes and fonts preview as you move through them.

Every change is written to the file right away and applied by hot reload, so the window itself is the preview. The command comes with nuntio and exists only inside its panes.

Editing in the terminal → Configuration reference →

Prefer a text editor? It's one plain TOML file at ~/.config/nuntio/config.toml on every platform, and nuntio-config keeps your comments.

[font]
family = "JetBrains Mono"
size = 14.0

# Follow the OS appearance
[theme]
light = "Solarized Light"
dark = "Tokyo Night"
