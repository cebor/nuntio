2/8 · Image paste and inline images

Screenshots in. Pictures out.

CtrlShiftV/⌘V

Copy a screenshot and paste it into the agent. nuntio writes the image to a private folder in the temp directory as image-1.png, image-2.png, … and pastes the path, quoted like a dropped file. Claude Code and omp attach it to the prompt. The folder is removed when nuntio exits.

Programs show pictures through the Kitty graphics protocol or iTerm2's inline images. They live in the grid, so they scroll, clear and get overwritten like text, in splits, over herdr and in WSL. omp picks the protocol on its own: nuntio sets PI_FORCE_IMAGE_PROTOCOL=kitty.

SequenceWhat nuntio does
OSC 1337 ; File=Inline image: PNG, JPEG, GIF (first frame), WebP, BMP; size in cells, px, % or auto.
APC G a=TKitty graphics: transmit and place RGB, RGBA or PNG, zlib, chunked; delete and query.
CSI 16 tReports the cell size in pixels.
3/8 · herdr agent status

Know which agent is waiting.

herdr.enabled = true

Run your agents in herdr and nuntio follows them. The status bar counts agents that are blocked, done or working, each tab gets a dot in the colour of its most urgent agent, and a banner tells you when an agent outside your view needs input. Click the count for the list, and an entry to jump there.

In a pane running herdr or tmux, nuntio's split, focus, resize and zoom shortcuts send the multiplexer's own keys, so the same keys work inside.

[herdr]
enabled = true

[status_bar]
enabled = true
items = [
  "agents", "<->",
  "cpu", "memory", "datetime",
]
4/8 · Notes

Notes next to your agents.

CtrlShiftN/⌘ShiftN

Prompts that worked, todos for the next session: notes open in a tab or a split and are plain Markdown files in one folder (notes.directory), so grep, git and your editor work on them too.

  • The preview renders headings, emphasis, code, lists, quotes and checkboxes as you type; the line under the cursor shows its Markdown.
  • Todos are - [ ] lines. Each note shows its progress, and CtrlO lists open todos across all notes.
  • Saved a second after you stop typing. Deleted notes go to .trash.
  • CtrlAltShiftN opens the notes in a split next to the focused pane.
5/8 · Settings

Settings that only offer valid values.

Ctrl,/⌘,

nuntio-config opens in a pane and edits ~/.config/nuntio/config.toml. Choices offer only valid values, themes and fonts preview as you move through them, and every change is written at once with your comments kept. Hot reload makes the window itself the preview.

Rather edit the file? Save it and nuntio applies it. A mistake shows a banner with the line, and the previous settings stay active. 20 themes are built in; add your own as TOML or .itermcolors, or set a light and a dark one that follow the OS.

[theme]
light = "Tokyo Night Day"
dark = "Tokyo Night"

6/8 · WSL

A real Linux PTY on Windows.

shell = { wsl = "Ubuntu" }

WSL tabs don't go through ConPTY. nuntio starts its helper nuntio-wsl inside the distribution; it owns a Linux PTY and sends the output over plain pipes, byte for byte. Inline images land where they should, and tab titles follow the program running in the distribution.

  • Every distribution in the shell menu
  • herdr and tmux found inside each distribution
  • Working directories carried between C:\ and /mnt/c
  • Falls back to ConPTY, with a banner, if the helper fails to start
